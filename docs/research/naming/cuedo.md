# Name check: Cuedo (2026-11-01)

## Who already uses the name
- **Cuedo Controls Pty Ltd** (Melbourne / Mooroolbark VIC, Australia, ABN 48 665 999 931), a software company doing control engineering and test infrastructure for MathWorks model-based design. It owns:
  - cuedo.com: RDAP registration 2019-10-11, Cloudflare, expires 2030-10-11. The site's title is "Home – Cuedo Controls".
  - cuedo.app: RDAP registration 2020-08-07, Cloudflare, expires 2027-08-07. It serves the same Cuedo Controls site.
  - cuedo.com.au: same site (about and services pages).
  - github.com/cuedo: an Organization named "Cuedo Controls", created 2020-08-06, with 7 repos (Haskell github-webhooks 40 stars, invoke-matlab, ...).

## Store and registry checks
- Google Play: the search page fetched by curl returned no `cuedo` package ids, only Cluedo and game apps (com.marmalade.cluedo2, com.clue.android). Web search also found no "Cuedo" app.
- App Store: web search found no "Cuedo" app. It did find several Cluedo apps (3rd Player for Cluedo, Cluedo Pal).
- F-Droid: the API returned 404 for package `cuedo`. Flathub: the search API returned 21 fuzzy hits and none of them is named cuedo. Snap: the find API returned no results. Product Hunt and SaaS: no hits in web search.
- pub.dev `cuedo`: 404, free. npm `cuedo`: 404, free.

## Domains
- Available (RDAP 404): cuedo.io and getcuedo.app.
- Taken: cuedo.com and cuedo.app (details above).

## Trademarks
- The TMview API rejected the request ("Request Rejected").
- USPTO tmsearch is a JS SPA, and its backend API refused the POST with MethodNotAllowed.
- WIPO Brand DB and IP Australia are JS-only, so the pages loaded but returned no parseable results.
- EUIPO was not queried directly.
- A web search for a "Cuedo" trademark found only CUDO, CREDO and CUE.
- **No database query worked, so trademark status is UNKNOWN.**
- Similarity risk: the name is one letter away from **CLUEDO** (Hasbro), a mark registered in classes 9 and 28 including games and apps.

## French and English
- English: "kyoo-doh". Readers may hear it as "kudos" or misread it as "Cluedo". The "cue + do" meaning is not obvious without being explained.
- French: "cue" is not a French word. A French reader would say "ku-é-do" or "ku-do". The "cu-" opening sits near "cul" (slang for backside): mild, but schoolyard-jokeable. A French reader is also quite likely to read it as "Cluedo".
- It does not clearly say "todo" or "reminder" in either language.

## Verdict
**minor-conflicts, borderline conflicted.** No todo or productivity app uses the name. However, an active software company owns the .com, the .app and the GitHub org, and the name is close to Cluedo.
