## Deprecations and changes found

1. **expo-widgets gained Android support in SDK 58 (2026-10-15).** The report's "iOS-only" is stale, and the RN/Expo widget score of 2 should rise. RN still has no Linux support, so the overall ranking holds. inferred
2. **Flutter in-SDK Material/Cupertino libraries:** formal deprecation in 3.50, due November 2026 (already in the report; confirmed).
3. **Impeller on Linux:** the Skia fallback will be removed in a future release (confirmed). R6 must not rely on the opt-out long-term.
4. **Full-screen intent:** since 2025-01-22 Play grants `USE_FULL_SCREEN_INTENT` by default only to calling and alarm apps targeting Android 14+. Other apps must send the user to the `ACTION_MANAGE_APP_USE_FULL_SCREEN_INTENT` settings screen and fill in a Play Console declaration. The report never mentions full-screen ("alarm-style") reminders. verified: https://source.android.com/docs/core/permissions/fsi-limits , https://support.google.com/googleplay/android-developer/answer/13392821
5. **Android 17:** the betas add a callback-based `setExactAndAllowWhileIdle(OnAlarmListener)` variant that cuts wakelock use, and restrict background audio, with alarm audio exempted in Beta 4. Only beta notes were found. Android 16 enforces JobScheduler/WorkManager runtime quotas more strictly, which affects background sync. verified (search summary): https://developer.android.com/about/versions/17/release-notes , https://developer.android.com/about/versions/16/behavior-changes-all
6. **Android developer verification:** enforcement started 2026-09-30 in BR/ID/SG/TH and goes global in 2027. Installs on certified devices then need an app registered by a verified developer. adb and the "advanced flow" still allow unverified sideloading. This affects distributing the APK outside Play, including through GitHub Releases. verified: https://android-developers.googleblog.com/2026/06/android-developer-verification.html , https://www.helpnetsecurity.com/2026/06/19/android-developer-verification-rollout-markets/
7. **system_tray (Flutter):** abandoned (confirmed).
8. **Play foreground-service policy:** geofencing is removed as an approved FGS use case from 2026-08-26 (search summary, not fetched). Relevant only if location-based reminders are planned. unverified

## Missing angles

- **Android developer verification and the sideloading timeline** (2027 global) for a public-GitHub app shipped as an APK, F-Droid or Obtainium. Needs a free or limited-distribution developer account.
- **Full-screen intent and alarm-style reminders**: the policy and declaration (above). This decides whether "can't-miss" reminders are possible without the user turning on a setting.
- **Whether a todo app qualifies for `USE_EXACT_ALARM` under Play policy**, and the "upcoming Play policy" note.
- **The Android 17 OnAlarmListener variant** (needs a live process, so it is not a replacement for PendingIntent alarms in a killed app) and the **Android 16 job quotas** for sync.
- **Expo SDK 58 Android widgets** shift the RN/Expo widget score. Linux remains the blocker.
- **ComposeNativeTray** (D-Bus SNI for Compose Desktop) narrows KMP's Linux gap. KMP still lacks a portal hotkey client and native Wayland.
- **Linux packaging (Flatpak vs Snap vs .deb/AppImage)** changes portal identity (hotkey_manager's sandboxed path), autostart, and notification persistence. Canonical stewardship points to Snap. The report does not discuss packaging at all.
- **The user's GNOME/Ubuntu version** decides GlobalShortcuts availability (GNOME 48+).
- **Desktop notification actions on Linux:** whether flutter_local_notifications Linux supports action buttons (snooze/done) via org.freedesktop.Notifications. Not checked.
- **The Flutter 3.50 timing**: it lands within weeks, so pin 3.47.9 now and plan the 3.50 migration (Material split).
- **GTK4 embedder PR #193405 status**: still not checked.
- **Primary Google source for Canonical stewardship**: still missing.
- **iOS later**: the WidgetKit/Swift requirement and APNs push for reminders are not discussed beyond scores.
